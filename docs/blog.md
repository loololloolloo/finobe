# Finobe blog — 1:1 reference restoration

## Verified reference

The user supplied the saved HTML document **Finobe Blog.html**, originally saved from:
https://blog.finobe.net/

The source is a home page generated by **Ghost 6.19** using **Casper**. It explicitly includes:

- HTML root class: dark-mode.
- Body classes: home-template, is-head-left-logo, has-serif-title, has-cover and is-dropdown-loaded.
- Navigation: HOME / MAIN WEBSITE and a search control.
- A full-width header cover image and centered Finobe logo.
- Six text-only article cards: post-card, post, no-image, keep-ratio.
- Post date and reading-time metadata (where available).
- Pagination text: Page 1 of 1.
- Footer structure: site-footer / copyright / gh-powered-by.

This replaces the incorrect older-Casper mock design (featured card + 3-column image cards).
The exact current Ghost/Casper built stylesheet is checked into
public/s/blog/casper-screen.css from TryGhost/Casper (MIT, see CASPER-LICENSE.txt).
Our public Blade views follow the HTML structure supplied by the user.
Small CSS and JS corrections live in public/s/blog/blog.css and finobe-blog.js.

**Important:** Finobe's original live blog still has title metadata and copyright bearing
"Aesthetiful". The user's website project specifically uses **Finobe** branding,
so our site title, footer and SEO metadata intentionally use Finobe Blog. This is a
deliberate branding change, not an exact string-level copy.

or CSS bytes. The original blog currently uses anti-bot protection, so this restoration
cannot guarantee those images are byte-identical. The existing project's
public/s/img/finnobe3logo.png and bannerlate2019-2.jpg are the local fallback.
Upload the original bannerlate2019-1.jpg to replace that fallback for pixel-level accuracy.

## Content fidelity

The supplied HTML contains **six** original post titles, timestamps, dated article
URLs, excerpts, and partial read-time labels. It does not contain the full post bodies.
Do not fabricate body text or auto-import incomplete material as published posts.
The Laravel blog continues to read published posts, tags and authors from its
own finobe database. A metadata-only snapshot is kept for reference at
research/finobe-blog/homepage-snapshot.json.

Public dated article routes use /YYYY/MM/DD/slug/ (e.g. /2026/05/18/rewrite-26/).
Legacy /slug/ URLs remain valid for previously created posts.
Admin post editing remains at /admin/blog. The search button now opens a local
search form backed by published-post queries, rather than relying on Ghost Sodo.
