# Starting places for new games

When someone creates a place, it starts as a copy of the baseplate for the client they picked:

| File | Client | Source |
| --- | --- | --- |
| `2016.rbxl` | 2016 | `RobloxStudio/content/FirstPlaceBasePlate.rbxl` from ThugShaker3D/Karma-2016-Client (Roblox Studio's own 2016 Baseplate template) |
| `2012.rbxl` | 2012 | Roblox's 2014 Baseplate template, `Baseplate.rbxl` from kay8o/OldRBLXTemplates (dated by its services: has StarterPlayer/GamepadService from 2014, none of the 2015+ ones). No authentic 2012 baseplate could be found. If this file is missing, 2012 places use `2016.rbxl` |
